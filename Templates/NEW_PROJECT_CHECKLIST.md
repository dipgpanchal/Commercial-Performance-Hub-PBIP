# New Power BI Project Checklist

## 1. Project Setup

- [ ] Create project folder
- [ ] Create PBIP project
- [ ] Create Git repository
- [ ] Add `.gitignore`
- [ ] Create README
- [ ] Create Architecture documentation
- [ ] Create CHANGELOG
- [ ] Create QA documentation
- [ ] Create Development documentation
- [ ] Create reusable templates
- [ ] Create initial Git baseline

## 2. Data Layer

- [ ] Identify source systems
- [ ] Document source tables
- [ ] Document transformation layer
- [ ] Document ELT / ETL approach
- [ ] Validate data refresh
- [ ] Validate data quality

## 3. Semantic Model

- [ ] Define fact tables
- [ ] Define dimensions
- [ ] Define relationships
- [ ] Define measures
- [ ] Organise measure folders
- [ ] Define calculation groups where required
- [ ] Define field parameters where required

- [ ] Define page structure
- [ ] Define navigation

- [ ] Define visual standards
- [ ] Define tooltips
- [ ] Define filters
- [ ] Define bookmarks
- [ ] Define interaction behaviour

## 5. QA

- [ ] KPI reconciliation
- [ ] Filter testing
- [ ] Visual testing
- [ ] Tooltip testing
- [ ] Navigation testing
- [ ] Edge-case testing

## 6. Version Control

- [ ] Initial baseline commit
- [ ] Push to GitHub
- [ ] Create feature branch
- [ ] Review Git diff
- [ ] QA
- [ ] Document change
- [ ] Commit
